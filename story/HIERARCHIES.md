# THE PREBUILT PATHS — established hierarchies, not invented ones

**In plain words —** Physics and biology already worked out how the world nests. We follow those
paths instead of making up our own, because they are the ones reality actually uses.

Every one of these is a **containment** hierarchy — each level is *made of* the level below — which
is exactly what a membrane tree is. So they drop straight in.

---

## 1. The cosmic path — matter, from the largest scale down

```
observable universe
  supercluster                    filaments and walls around near-empty voids
    galaxy cluster / group
      galaxy                      stars, gas, dust, bound
        molecular cloud           where stars actually form
          star system             ← WE START HERE
            star
            planets
              moon
```

**The top has an edge.** Above superclusters — between roughly 30 and 200 megaparsecs — structure
simply stops; cosmologists call it the **End of Greatness**. The hierarchy is not infinite upward,
which means the tree has a genuine top and we are not obliged to invent one.

**WHAT THIS FINDS IN OUR TREE:** we go `theCloud → theSolarSystem` directly. The real path has
**galaxies between them** — a cloud does not become a solar system on its own, it collapses inside a
galaxy, in a molecular cloud, one of thousands forming at once. Missing levels, named:

```
theCloud → [ theGalaxy → theMolecularCloud ] → theSolarSystem
```

## 2. The body path — matter, from the smallest scale up

```
atom
  molecule
    organelle                     a membrane-bounded machine inside a cell
      cell                        the smallest unit that is alive
        tissue                    like cells doing one job
          organ                   tissues grouped to one function
            organ system
              organism            ← theHuman
```

This is the route from matter to a person, and it is **already segmented into membranes** — every
level is literally bounded, and the cell's boundary is a membrane in the original sense.

## 3. Where the two paths meet

They are one ladder, joined at the planet:

```
universe … galaxy … star system … planet … ground … [ atom … cell … organ … ] … human
```

The same seed runs the whole length. A human is made of atoms that were made in a star that formed
in a cloud inside a galaxy — so `theHuman`'s origin really is Earth, and Earth's origin is the
chapter we already wrote.

---

## How to use this

- **Do not invent a level.** If a step feels missing, check these paths first — it probably is one.
- **Each level gets `the` and `a`** — `theGalaxy` (what a galaxy is) and `aGalaxy` (ours).
- **Depth is a budget.** These paths run further than the game needs in both directions; the story
  decides where to stop, but it may not *skip*.
