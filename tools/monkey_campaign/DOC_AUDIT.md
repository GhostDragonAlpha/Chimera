## Completion of bounded queue tasks

Each returned brief grants read-only investigation of its sources and writes solely
inside its named report directory. It grants no production source edits or hardware use.
The claim remains associated with its worker/generation after expiry; never reassign it
from silence. Workers report and hand off through existing slot APIs. The coordinator
reviews evidence, confirms cessation, releases the slot and publishes the next ready
brief. Completed task IDs are retained, preventing accidental repeat claims.

This queue is an immediate concrete critical-path bridge, not a claim that all 83 items
have been imported into a fully automatic task server. Broad implementation dispatch
continues through the existing coordinator and its scoped task briefs.
