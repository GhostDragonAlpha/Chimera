## RULE 0 — STATEMENT

THE THEORY (scoped, falsifiable): a cached verification result (e.g. "record set S on
baseline B reproduces trace T bit-exact") is reusable EXACTLY while its SEMANTIC dependency
closure is unchanged — and that closure is COMPUTABLE from record content and the declared
boundary (typed reads/writes, record-input producer edges, reset semantics, numeric policy,
domain, horizon), never inferred from names, text, or full-content digests alone (metadata
is not semantics: a citation cannot change a bit). Additionally: a COMPLETE lossless replay
match (every boundary output AND state transition, floats by uint64 bits, never decimals)
+ physics-unchanged + measured determinism ENTITLE the same-trajectory-by-induction
certificate — the narrow result that lets a law-swap skip a full re-run WHEN the swap
provably preserves outputs in-domain. A description survives any result; a theory can lose.

## FALSIFIERS (named before the run)

- **F-STALE-CERTIFICATE**: any cached result reported REUSABLE after a semantic dependency
  changed (producer semantic content, reset semantics, numeric policy, domain, or horizon)
  fires. Probes: fixtures (a), (b), (c). One VALID verdict on any of them fires. (The
  certificate path probes it too: a waiver granted over drifted dependencies fires.)
- **F-UNJUSTIFIED-RERUN-SKIP**: a full re-run WAIVED without every certificate assumption
  holding — incomplete match ledger (any mismatch, or lossless=false), physics drift,
  determinism unproven (no double-run byte identity), dependency drift, or horizon not
  covered by the certified horizon — fires.
- **F-OVER-INVALIDATE** (the (d)-fixture guard; this lane exists to remove the verification
  bottleneck, and a false invalidation is that bottleneck un-fixed): a cached result declared
  INVALIDATED by a metadata-only change (semantic digests all equal) fires.
