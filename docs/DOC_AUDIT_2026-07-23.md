## D. Internal contradiction in `README.md`

The workflow diagram and the step that explains it disagree:

```
line 25:  → verified (preliminary) → HUMAN OBSERVATION (the true collapse)
line 48:  8. HUMAN OBSERVATION ... Agents DO record observations — attributed to
             simulation evidence (automation amendment 2026-07-07)
```

The diagram says a human collapses the feature; step 8 says agents do it from simulation
evidence, and `CLAUDE.md` agrees with step 8. **A reader following the diagram will wait
for a human who is not coming.**

**Suggested fix:** change the diagram line to `→ AUTOMATED OBSERVATION (the true
collapse)`. One line, removes the ambiguity.
