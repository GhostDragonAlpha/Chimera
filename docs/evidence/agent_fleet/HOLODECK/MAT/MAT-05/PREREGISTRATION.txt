## DERIVED BOUND (card threshold policy: derive the fixture-specific bound
   before implementation tests)

The card's nondimensional control for this domain is SPECIFIC GRAVITY
(SG): density = SG x rho_basis, rho_basis = 1000 kg/m^3 (water, 4 C --
the declared basis; SG is Dimension.DIMENSIONLESS in MATH-01's algebra,
so the composition SG x basis carries dimension (L^-3 M) exactly).
Admissible SG domain DERIVED, not tuned:
  - lower: SG > 0 strictly. A nonpositive SG means a nonpositive density,
    which the calibrated plane's own physics gate refuses
    (material_contract.py PHYSICALLY_INVALID: negative density).
  - upper: SG <= 22.59. Osmium 22.59 g/cm^3 (SG 22.59 against water) is
    the densest naturally occurring elemental solid at standard
    conditions -- an absolute physical ceiling for any real-material
    claim; a preset claiming more presents fiction as physics.
  - fixture band (what the deployed plane actually ships, measured from
    its constants, NOT a gate): plush_stuffed 250 kg/m^3 -> SG 0.25,
    knit 300 -> 0.30, acrylic 1180 -> 1.18; Wood Handbook white oak
    SG 0.68 (matter_data.py:172). All inside (0, 22.59].
A preset authored with SG outside (0, 22.59] is refused by name before
any arithmetic. The bound is fixed NOW; it is never widened after a run
(AGENTS.md: do not widen failed tolerances).

## REFERENCE MODEL CONTRACT (fixed before implementation)

stdlib-only (+ the MATH-01 import), <300 lines, at
reference/mat05_reference_model.py:

- TWO separated stores, two classes, no shared mutable state:
  PresetStore (synthetic) and CalibratedStore (calibrated). Every
  PresetRecord is frozen and carries synthetic=True, a nonblank
  synthetic_label naming the fiction, provenance=SYNTHETIC, and its
  declared domain. Every CalibratedRecord is frozen and carries
  provenance in {researched, parent, derived}, a nonblank source locator
  and nonblank conditions (MAT-01's admission semantics, restated here
  as the other side of the partition).
- SUPPORTED AUTHORING DOMAINS (closed, declared set for the synthetic
  plane): {plush_stuffed, knit, acrylic} -- the domains the deployed
  preset plane actually serves. author_preset(domain=...) outside the
  set -> refusal unsupported_domain (explicit, named, listing the
  supported set -- the matter_data.py Uncited pattern).
- author_preset(...) gate order: nonblank label (missing_label) ->
  finite value (nonfinite) -> supported domain (unsupported_domain) ->
  SG in (0, 22.59] when an SG control is authored (sg_out_of_domain) ->
  fraction controls in [0, 1) (fraction_out_of_domain). Success returns
  a frozen PresetRecord in the preset store ONLY.
- admit_calibrated(...): the calibrated door. Refuses blank
  source/conditions (missing_basis), nonfinite (nonfinite), provenance
  outside {researched, parent, derived} -- and a record whose provenance
  says researched/parent/derived while its declared kind is SYNTHETIC
  (fictional_claim: presenting fiction as measured). Success returns a
  frozen CalibratedRecord in the calibrated store ONLY.
- THE SEPARATION DOOR (the card statement's surface):
  calibrated_get(name, prop) serves ONLY from the calibrated store; a
  name that exists only in the preset store -> refusal
  synthetic_not_calibrated. preset_get serves only the preset store and
  always returns the record with its synthetic label intact.
- present_as_measured(preset_record, ...) -- the FALSIFIER API: every
  path from a fictional preset to a measured claim is refused by name:
  provenance mutation on a frozen record raises; label overwrite raises;
  serving through the calibrated door refuses; admitting the same values
  as researched with a fabricated source refuses fictional_claim; a
  foreign/dict impostor into either store is refused at the serve-time
  boundary type check.
- sg_to_density(sg, basis_kg_m3): the nondimensional control's real
  caller. Accepts only a domain-checked SG and a positive finite basis;
  returns a MATH-01 Quantity(value = sg*basis, Dimension (L^-3 M)) --
  composition deferred to MATH-01's exact algebra (cited, not
  reimplemented). Domain violations refuse before arithmetic.
