## REFERENCE MODEL CONTRACT (fixed before implementation)

stdlib-only (+ the MATH-01 import), target < 450 lines, at
reference/mat04_reference_model.py. Domain fixture (DECLARED, derived below,
not tuned): a uniaxial tension identification — extension d = k*F + d0,
theta = (k [m/N], d0 [m]); k is the specimen's longitudinal compliance,
d0 the zero-load offset. Synthetic declared material: gauge L = 0.1 m,
area A = 1e-4 m^2, E = 2.0e9 Pa -> k_true = L/(A*E) = 5.0e-7 m/N exactly;
d0_true = 2.0e-5 m. Both true values enter as EXACT closed-form constants
of the declared fixture, recomputed independently by the control from
L, A, E via Fraction arithmetic.

- Experiment: (exp_id, load Quantity [N], observed extension Quantity [m]
  with declared unit, noise sigma). The observation arrives with a UNIT;
  unregistered units refuse (MATH-01 declared-only registry, cited).
- Design matrix: rows [F_i, 1]; each column carries the MATH-01 Dimension it
  implies (col 0: Dimension.N; col 1: DIMENSIONLESS). Design gate: for every
  column, column Dimension x parameter Dimension == observation Dimension
  (exact MATH-01 algebra) or refuse `dimension_mismatch` BEFORE any fit.
  Rank gate: exact-Fraction determinant of the Gramian F^T F; |det| == 0
  refuses `rank_deficient_design` (unidentifiable is refused, never fitted).
  Noise gate: sigma finite and > 0 else `invalid_noise_sigma`.
- fit(experiments, design) -> FitResult (frozen dataclass): theta_hat via
  exact-normal-equations solve (float64 partial-pivot Gaussian elimination
  on the 2x2/3x3 system), residual scale s^2 = SSR/(n-p), parameter
  covariance C = s^2 (F^T F)^-1, CORRELATION MATRIX
  R_ij = C_ij/sqrt(C_ii*C_jj) (dimensionless — the card's
  parameter-correlation output), dof = n-p.
- confidence interval: theta_j +/- t_{1-alpha/2, dof} * sqrt(C_jj) — the
  card's confidence output. t quantile computed stdlib-only: Simpson
  integration of the Student-t pdf + bisection inversion of its CDF
  (no table constants inside the model).
- declare_predictive_band(fit, load) -> Prediction (frozen): mean prediction
  Quantity [m] and 95% band half-width t * s * sqrt(1 + x*' (F^T F)^-1 x*),
  carried as a MATH-01 Quantity of Dimension L. Declared BEFORE reveal.
- judge(prediction, observed) -> verdict in the CLOSED vocabulary
  {AGREES, DISAGREES}: |observed - mean| <= half-width -> AGREES else
  DISAGREES. The judge is the card prediction's surface. Guards:
  observed experiment present in the training ledger refuses
  `heldout_overlaps_training` (a training point agreeing with its own fit
  is NOT validation); empty held-out set refuses `no_heldout_evidence`.
- choose_design(candidate_designs) -> D-optimal choice: maximize
  det(F^T F) by exact-Fraction determinant (the card's experimental-design
  mathematics); ties refuse `ambiguous_design`.
