## REFERENCE MODEL CONTRACT (fixed before implementation)

stdlib-only (+ the MATH-01 import), <300 lines, at
reference/mat01_reference_model.py:

- PROPERTY_SCHEMA: closed table mapping property type -> allowed unit
  family (each family: {unit -> scale to canonical SI}), sign gate, and the
  MATH-01 Dimension the family denotes:
    density        {kg/m^3:1, g/cm^3:1e3}              dim (L^-3 M),  positive
    modulus        {pa:1, kpa:1e3, mpa:1e6, gpa:1e9}   dim Pa,        positive
    surface_energy {j/m^2:1}                           dim (M T^-2),  nonnegative
    dimensionless  {1:1, ratio:1, sg:1}                dim 1          (fraction: [0,1])
- admit(raw: dict) -> MaterialParameter: the ONLY path from raw data to a
  record. Gate order: finite real value (NONFINITE) -> unit registered
  (INVALID_UNIT: unknown_unit) -> unit family matches the property type's
  MATH-01 Dimension (INVALID_UNIT: unit_dimension_mismatch) -> provenance
  in {researched, parent, derived} -> derived requires nonblank derivation
  (MISSING_BASIS) -> nonblank source AND conditions (MISSING_BASIS: a
  parameter without stated reference conditions is not admissible) ->
  sign/fraction gates (INVALID_VALUE). Success returns a frozen
  MaterialParameter carrying a MATH-01 Quantity (SI-scale value + exact
  Dimension), the original unit, provenance, source, conditions, and
  derivation.
- snapshot(params) -> immutable mapping view (types.MappingProxyType over
  name -> record). Mutation attempts raise; serving re-checks membership
  and type at the boundary (the MATH-01 model's A1-3 analog: a hostile
  dict injection into the bag is refused at serve time, not trusted).
- THE REAL CALLER (the card prediction's surface):
  bulk_mass(density_parameter, volume_quantity) -> MATH-01 Quantity of
  Dimension M — accepts ONLY an admitted MaterialParameter and a MATH-01
  Quantity of Dimension L^3; anything else (raw dict, bare float, string,
  duck-typed impostor) is refused `legacy_input` BEFORE any arithmetic;
  dimension mismatches refuse via MATH-01's `dimension_mismatch`.
- density_from_sg(sg_parameter, basis_value, basis_conditions): declared
  -basis derivation; missing/blank conditions refuse MISSING_BASIS before
  any arithmetic; nonpositive/nonfinite basis refuses INVALID_VALUE; the
  derived record carries its arithmetic (a derivation string with the
  inputs), per the card's "reference conditions" mathematics.
