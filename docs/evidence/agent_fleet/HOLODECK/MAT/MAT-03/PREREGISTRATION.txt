## UNITS BACKBONE (MATH-01 citation duty)

The reference model imports MATH-01's integrated typed-quantity algebra
(docs/evidence/agent_fleet/HOLODECK/MATH/MATH-01/reference/
math01_reference_model.py: Dimension over exact Fraction (L,M,T) exponents;
Quantity with named dimension_mismatch refusals; UnitRegistry
declared-only scale conversions). Independence is claimed from the AUDITED
deployed code (tools/matter_data.py, tools/material_contract.py), NOT from
the MATH-01 backbone — the task packet designates MATH-01 the units
backbone of this lane. Where the material domain touches dimensional
analysis (measured property values composed/compared as typed quantities,
e.g. Pa-modulus x dimensionless strain, Pa x m^3 -> J for a derived
work-of-fracture record), the model defers to MATH-01's algebra and cites
it. The model adds what MATH-01 deliberately does not have: the DATASET
layer (versioned, condition-indexed measured records with uncertainty and
citations) and an AFFINE temperature family (K canonical; degC offset
+273.15), which is outside MATH-01's scale-only registry by construction —
a scale-only conversion of degC would map 0 degC to 0 K and is refused by
design (R1(c) pins the offset; R2(g) refuses undeclared families).

## REFERENCE MODEL CONTRACT (fixed before implementation)

stdlib-only (+ the MATH-01 import), <320 lines, at
reference/mat03_reference_model.py:

- CONDITION AXES (the card's three), each a declared unit family with a
  canonical unit and (for temperature) a declared affine offset:
    temperature   {k: scale 1, degc: scale 1 offset +273.15}   canonical K
    moisture      {fraction: 1, percent: 0.01}                 canonical fraction
    strain_rate   {1/s: 1}                                     canonical 1/s
  Condition values convert to canonical at import; an unregistered unit
  refuses unknown_condition_unit; a value outside the dataset's declared
  envelope refuses condition_outside_envelope.
- KNOWN_SOURCES: a citation registry (id -> locator) of sources the fleet
  has seen before. METADATA ONLY: no admission gate consults it (this is
  the card falsifier's lesson, enforced structurally; R3(e) audits the
  gate list).
- MeasuredRecord (frozen): property name, MATH-01 Quantity (declared unit
  family -> SI value + exact Dimension), uncertainty (>0, finite, same
  unit), full condition map (all axes, canonical), citation (source id +
  locator + note, stored VERBATIM).
- import_dataset(payload, citation, known_sources) -> MeasuredDataset:
  the ONLY path from raw data to a stored dataset. Gate order, each
  refusal NAMED, none silent:
    missing_source_identity   blank/absent citation locator, id, or note
    identity_mismatch         payload declares content_sha256 and the
                              recomputed sha256 over the canonical JSON of
                              the payload differs (declared identity must
                              match measured content)
    nonfinite                 non-numeric/NaN/inf property value or
                              condition
    bad_value                 property violates its own physics (e.g.
                              negative modulus)
    missing_uncertainty       absent/blank/nonpositive uncertainty
    unknown_unit              property unit not in the property's declared
                              family
    unknown_condition_unit    condition unit not in the axis family
    missing_condition         a record omits one of the dataset's declared
                              axes (temperature, moisture, strain_rate —
                              all three are REQUIRED context for this card)
    condition_outside_envelope a condition outside the dataset's declared
                              [lo, hi] per axis
    duplicate_version         re-import of an existing (id, version)
    version_regression        a version <= the dataset's current max
    bad_version               non-integer or < 1
  Success stores an immutable MeasuredDataset: id, version, the VERBATIM
  citation, the recomputed content_sha256, declared envelope, and the
  records; prior versions stay byte-preserved and readable (history is
  append-only; no in-place mutation, no silent overwrite).
- propagate_sum(a, b) / propagate_product(a, b): uncertainty propagation
  over measured records of the same property: sum -> u =
  sqrt(ua^2 + ub^2); product -> u/c = sqrt((ua/a)^2 + (ub/b)^2); values
  compose as MATH-01 Quantities (dimension composition cited to MATH-01).
  The derived record carries BOTH parent citations and the arithmetic
  string; missing parent citation refuses missing_source_identity.
- interpolate(dataset, property, query_conditions): requires ALL declared
  axes present in the query (missing_condition) and every query condition
  STRICTLY WITHIN the measured grid of the varying axis (outside the
  [min, max] of measured values refuses outside_measured_envelope — no
  extrapolation, that is inventing measurement); linear interpolation of
  value AND uncertainty between the two bracketing records; the result
  carries BOTH bracketing citations (source identity survives
  interpolation) and is marked interpolated.
- ALL refusals are Mat03Refusal(reason, message) — machine-checkable
  reason, verbatim detail.
