## STATEMENT (theory, per RULE 0)

The filesystem mailbox is safe for cross-agent coordination under single-host,
single-user assumptions: same-volume os.replace() posting is atomic per message, so
concurrent posters cannot corrupt or lose each other's messages; take moves (never
deletes) so history is append-only and audit survives consumption. Its limits are part
of the contract: sender identity is self-declared (audit-by-visibility, not
attestation), delivery is poll-based (no push, no delivery guarantee — an agent that
never polls never receives), and content is coordination-only (nothing load-bearing
rides it). Declaring these limits is what makes the tool safe to rely on.

## PREDICTION (stated before any edit)

1. The atomicity probe posts N=100 messages from 4 concurrent OS processes into one
   temp-root inbox; after all processes join: exactly 100 message files exist, all
   parse as JSON, all ids are unique, zero ".tmp-*" files remain — ZERO LOST.
2. take is idempotent (second take: count 0, no exception) and served is append-only

   was posted; no served file ever deleted).
3. Name-safety refusals fire (SystemExit) for separators, traversal, leading dots, and
   reserved characters — with zero filesystem writes for the refused post.
4. The suite's live-tree guard passes: the listing of E:\ChimeraWork\mailbox is

   which change nothing).
5. The repo copy's CLI is behavior-identical to the live v0 (same subcommands, flags,
   output JSON keys; default root unchanged).

## FALSIFIER (named before the run)

- Any lost message: fewer than 100 files, any unparseable message, duplicate ids, or a
  surviving ".tmp-*" partial after the probe joins.
- Any take deleting history: a served file disappearing, served count decreasing, or
  served bytes differing from the posted bytes.
- Any test touching the live tree: the live-root listing changes across the suite, or
  any test path resolves under E:\ChimeraWork\mailbox.
- A name-safety refusal that still writes (directory created or file left behind).
- A repo copy whose default CLI behavior differs from the live v0.
