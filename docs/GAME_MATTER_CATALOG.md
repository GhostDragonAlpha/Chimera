# Game matter catalog and interaction matrix

Revision: 2026-10-23.v1. Generated from the [existing science-funnel catalog](../tools/science_funnel/data/game_matter_catalog.json) by [its read-only auditor](../tools/science_funnel/game_matter_catalog.py). Product priorities live in the [main plan](GAME_PLAN_ACTION_RPG.md#112114-working-interactions-then-the-games-matter-catalog).

**34 material/recipe entries; 29 interaction scenarios.** All 23 original material candidates and all 16 broader ontology recipe groups are accounted for. Three bounded metal recipes are available; the rest need material-specific data, coupling or qualification. This is the complete coverage list for the currently described game, with optional broader scope retained. It is not a claim that every grade, species or future environment has already been chosen.

The first rescue uses **aluminum, stainless, a ground/support material, a textile/rope material and a compliant pad**. The alloy is an optional additional brace material. Only the metal cards currently have the complete sourced route in this set. The other three roles can begin with explicitly authored physical surrogates using existing native mechanisms.

Start with an explicitly labeled mechanical assembly from admitted parts and bounded actuation. Biological appearance does not certify muscle/bone/skin. Tissue rows remain required for later biological fidelity.

## What works now

- NIST 6061-T6 and 304 cards: source inspection, bounded isothermal elasticity, native contact and reusable Blender assets. Density, Poisson ratio and contact coefficients remain authored. The original direct aluminum/stainless contact and continuation receipts are stale; the newer alloy construction exercises the parent cards within its own scope.
- First 95:5 alloy: conserved nominal composition, five thermodynamic snapshots, a 300 K elastic field, load transfer to aluminum and deformation under stainless. Nine solid reference checks and nineteen Blender checks remain current. The finest axial-bar error is 0.8361%; the loaded sag is 0.33154 mm versus 0.00601 mm with stainless contact disabled. These do not qualify mesh-converged bending or a manufactured alloy. Two phase proxies cover 12.0444 mass%.
- Generic cloth, rods, FEM pads, rigid/static supports, layered assemblies and stitches already have workshop mechanisms. Historical evidence is useful, but does not certify cotton, silicone, bone, wood or a new material pair. Uniform-tension membranes are separate from elastic cloth and tissue.
- Composition snapshots are separate from stirring, heat transfer and solidification. Appearance rendering is separate from optical-field physics. Current coupled examples run offline; no real-time game budget is established.

A boiling-water reference uses local pressure; altitude is only a way to estimate that pressure under a declared atmospheric model.

## Identity, state and detail rules

- Reuse the existing 118 element identities; element identity is not a continuum material law.
- Material recipe + composition + phase/preparation + geometry + state/history + interface law determine the asset. Names and render colors do not.
- Water/ice/vapor remain one inventory with state-specific laws; wood grain, weaving, porosity and cure are preparation/state, not new chemical elements.
- Composition fractions live on the existing simplex where total inventory is positive; empty/vacuum has zero matter inventory and undefined composition. Fields and imposed boundary conditions are accounted separately.
- Stored and dissipated energy and time/history have one declared owner; do not add a second account for DFT/CALPHAD/continuum versions of the same energy.
- DFT and thermodynamic databases provide offline evidence; dynamic game response needs bounded native/reduced laws. No per-frame DFT or universal interpolation claim.
- Fire, sound, light, electricity and magnetic fields are interaction/state channels, not extra bulk substances. Plasma is a selected ionized state; no current encounter selects it.
