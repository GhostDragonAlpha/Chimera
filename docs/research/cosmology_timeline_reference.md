## Purpose

and physical processes — relevant to theCooling, theDensityClock, and theEmptying

## Cosmic Density Evolution

### Energy Density as Function of Time
```
ρ_r ∝ (1+z)⁴        # radiation (photons + neutrinos)
ρ_m ∝ (1+z)³        # matter (baryonic + dark)
ρ_Λ = const         # dark energy (cosmological constant)
```

### Key Transition Points
| Transition | z | Temperature | Time |
|-----------|---|-------------|------|
| Matter = Radiation | 3,377 | 9,215 K | 51.7 kyr |
| First star formation | ~20 | ~50 K | 150 Myr |
| Dark energy = Matter | ~0.5 | 2.4 K | ~9 Gyr |

## Scale Factor Evolution
```
a(t) ∝ t^(1/2)     (radiation-dominated)
a(t) ∝ t^(2/3)     (matter-dominated)
a(t) ∝ exp(√(Λ/3)·t)  (dark energy-dominated)
```

## Hubble Parameter Evolution
```
H(z) = H₀ × √[Ω_r(1+z)⁴ + Ω_m(1+z)³ + Ω_k(1+z)² + Ω_Λ]

For z > 1000: H(z) ≈ H₀ × √[Ω_r(1+z)⁴]          (radiation-dominated)
For 1 < z < 3400: H(z) ≈ H₀ × √[Ω_m(1+z)³]      (matter-dominated)
For z < 0.5: H(z) ≈ H₀ × √[Ω_Λ]                  (dark-energy dominated)
```

## Time-Redshift Relations

### Radiation-dominated (z > z_eq ≈ 3,400)
```
t ≈ (2/3) × 1/(H₀√Ω_r) × (1+z)^(-2)
```

### Matter-dominated (z_eq < z < ~0.5)
```
t ≈ (2/3) × 1/(H₀√Ω_m) × (1+z)^(-3/2)
```

### Matter + Λ dominated (z < ~0.5)
```
t = (2/3) / (H₀√Ω_Λ) × arcsinh(√(Ω_Λ/Ω_m) × (1+z)^(-3/2))
```
