# Deep Space Trader: Educational Frontier

## Tagline
Learn real science exploring an alien world. No loading screens. No fictional lore. Actual geology, meteorology, and astronomy.

## Short Description (Steam)
Deep Space Trader is an educational RPG that teaches real science through exploration. Walk through a procedurally-generated canyon and identify rock types by their visible strata. Read the clouds to predict weather. Navigate by the stars. Every environment teaches something real — no fake elements, no hand-holding, just the universe as it actually works.

Built with Unreal Engine 5.8. Volumetric clouds. Procedural terrain. Real-time day/night cycles. Educational content written with scientific reviewers.

## Features
- **Real Geology**: Identify sedimentary sandstone, metamorphic schist, and igneous basalt by visible characteristics in canyon walls
- **Real Meteorology**: Read cloud formations to predict weather — cumulus means fair, cumulonimbus means shelter now
- **Real Astronomy**: Stars shift position with planetary rotation. Constellations change with location.
- **Educational Scanner**: Point at any rock, cloud, or star and learn real science behind what you're seeing
- **No Fictional Lore**: Every fact in the game is verifiable in the real world
- **Procedural Alien World**: Each playthrough generates unique terrain with its own geological history

## About This Demo
This is an early prototype demonstrating the educational environment system. Walk through a procedurally-generated canyon with 16 educational markers covering geology, meteorology, and astronomy. The full game will include trading, ship navigation, NPC faction relationships, and orbital mechanics — all teaching real science.
