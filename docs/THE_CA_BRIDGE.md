# THE CA BRIDGE — how the certified membrane system feeds the CA system

Written 2026-09-13, after the kernel battery (B1-B5) passed and the
first body parts (feet) rendered as membranes. The operator's question:
how does our new membrane system affect the CA system. This note is the
answer of record.

## THE IDENTIFICATION

The membrane law (the operator, standing): every membrane encompasses
collections of triangles and CA triangle types, programmed with the
mathematical characteristics of its material.

The battery certified five LOCAL RULES, each material-keyed:

    B1 scratch:      pairwise tip/plate rule -> groove (force, radius)
    B2 bonds:        a third material between neighbors -> cure strength
    B3 tensile web:  capacity per link -> weakest link propagates
    B4 drape:        local constraint -> shell geometry
    B5 residency:    the cells live on the GPU; Python posts intents

These are CELLULAR RULES: local state, material-programmed constants,
neighbor coupling, emergent global behavior. The CA system is the
machine that runs them per triangle per tick. The battery did not just
pass tests — it specified the CA rule table with falsifiers.
