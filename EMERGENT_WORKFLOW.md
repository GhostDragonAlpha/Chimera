# The Emergent Workflow

> Everything is trained. Nothing is authored. Questions are typed in chat first.
> The element catalog has 69,749 variables. The trainer does 30,000 evals/sec.
> Every game artifact starts as a constraint set and emerges from the trainer.
> The Mirror of Erised steers everything. A costless life produces a dim signal.

## The Pipeline

```
META-CONSTRAINT  →  40 QUESTIONS  →  CONSTRAINT SET  →  CATALOG QUERY  →  DOMAIN
(Mirror)           (typed in chat,  (walls only)       (find elements)   (seed/
                    saved to graph)                                      mutate/
                                                                         measure)

     →  TRAIN  →  DECODE  →  LEVEL  →  GRAPH
        (walls     (MCP      (emergent_  (Graphify MCP
         only)      spawn)    world)       records everything)
```

Every step is data. Nothing is hand-authored.

## The 40-Question Document

Every feature gets 40 questions TYPED IN CHAT before any code. The typing is the reflection.
The file is the record. Questions cover identity, constraint, scale, catalog coverage,
Mirror connection, composition, training, and depth.

```
python -m core.forty_questions generate <name> <parent>    # create skeleton
python -m core.forty_questions answer <name> <qid> <text>  # fill answer
python -m core.forty_questions show <name>                 # view document
```

Depth verdict: 0-9 unexplored, 10-19 explored, 20-29 adequate, 30-40 deep.

## The Auto-Decomposer

Reads the DNA graph, finds parent rungs with few sub-rungs, prioritizes by Mirror weight,
generates constraints + domains + 40-question documents, and trains all sub-rungs in
parallel. Skips features that already exist in the graph.

```
python -m core.auto_decomposer <parent> <n_clusters>
python -m core.auto_decomposer   # auto-select highest Mirror gap
```

## The Graph (Graphify MCP Server)

`graphify-mcp.exe` serves the DNA graph over MCP. Configured in `.mcp.json`.
Stores every feature, training run, 40Q depth, Mirror connection, and gap.
Feeds back into training via `graph_context()`.

```python
from core.forty_questions import graph_context
ctx = graph_context()  # returns n_features, n_mirror, n_gaps, depth_counts
```

## Step 1: Constraint Set

JSON at `docs/constraints/<name>.json`. Walls only — no maximize/minimize.

```json
{
  "name": "solar_system_stellar_classification",
  "walls": ["Star color varies with surface temperature", "Spectral class determines light output"],
  "element_query": {"categories": ["Star", "Spectral", "Luminosity"], "classes": []}
}
```

## Step 2: Catalog Query

```python
import json
catalog = json.load(open('docs/element_catalog.json'))
elements = [e for e in catalog['elements']
            if any(cat in e.get('category','') for cat in constraint['element_query']['categories'])]
```

## Step 3: Domain

Generated by `core/domain_generator.py`. For high-dimension domains, add `measure_batch` for GPU.

```
python -m core.domain_generator docs/constraints/<name>.json
```

## Step 4: Train

```
python -m core.trainer --domain core.trainables.generated.<name> --objective docs/objectives/<name>.json
```

Walls only. The trainer reports which genomes satisfy all constraints.

## Step 5: Decode

`core/decoder.py` reads trained winners and MCP-spawns artifacts in `emergent_world`.

```
python -m core.decoder
python -m core.decoder verify
```

## Step 6: Thought Chain

`docs/THOUGHT_CHAIN.md` records the complete reasoning. Next session starts at
section 10 and executes steps A through G in order. No questions.
