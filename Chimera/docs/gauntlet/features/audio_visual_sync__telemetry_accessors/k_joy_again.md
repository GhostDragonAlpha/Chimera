# Kindergarten: again — audio_visual_sync/telemetry_accessors

The player does it a second time because the first step ANSWERED — the itch is
rhythm. A footstep that lands on time invites the next one the way a drum
invites a beat; walking becomes self-scored music, and sprinting doubles the
tempo just to hear it. What the first use plants is trust: the ground replied
once, so it will reply again. audio_visual_sync/telemetry_accessors is how we
keep that promise every build — the repeat itch dies the first time the reply
comes late.
