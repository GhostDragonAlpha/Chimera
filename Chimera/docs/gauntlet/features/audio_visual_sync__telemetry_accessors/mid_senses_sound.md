# Middle: the sound signature — audio_visual_sync/telemetry_accessors

Source: boot-on-regolith — granular crunch, low-mid weight, no tail (vacuum-
adjacent moon air keeps it dry). Trigger: the footfall event from the
locomotion animation, one per contact, velocity-scaled. Mix priority: above the
wind bed, below UI and voice; footsteps are the body's metronome and duck for
nothing except narrative. Where silence is the better choice: standing still.
The ground must never emit a phantom step — silence between strides is what
makes the next crunch land — and the accessors enforce that silence too: a
count that rises while velocity is zero is a bug the ear might excuse but the
telemetry for audio_visual_sync/telemetry_accessors must not.
