# Master: four lenses of access — audio_visual_sync/telemetry_accessors

- **Visual** (low vision / colorblind): synced footsteps are already an
  accommodation — audio carries ground truth when sight cannot; the
  accommodation to ADD is per-surface sound distinction strong enough to
  navigate by ear alone (sand/rock/metal must be blind-distinguishable, which
  the per-surface accessors can verify by existing).
- **Motor** (one-handed / low precision): walking is held-key, no rhythm or
  timing demanded of the hands — keep it that way; never gate anything on
  step-timed input. The debounce also forgives tremor-induced key jitter.
- **Cognitive** (memory / attention): sync is preattentive — it asks for zero
  working memory; the accommodation is consistency: identical cause->sound
  mapping everywhere, no context-dependent footstep meanings to learn.
- **Auditory** (deaf / hard of hearing): the triad's other channels must carry
  the same truth — footprint decals and camera bob deliver step feedback
  visually/kinesthetically; a later caption pass can surface surface-type
  glyphs. The accessors help here too: they timestamp the VISUAL contact,
  so a visual-feedback-only build can still be sync-verified.
