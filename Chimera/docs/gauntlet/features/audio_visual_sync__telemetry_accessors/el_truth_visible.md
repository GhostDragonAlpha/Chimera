# Elementary: player-visible truth — audio_visual_sync/telemetry_accessors

What the player perceives: the crunch is AUDIBLE at the instant the boot
visibly lands — sound and screen agree. That agreement is the only
player-facing surface this feature protects; the accessors themselves are
deliberately invisible.

H-14 discipline applies with teeth here, because this feature is the H-14
trap's natural habitat: verified-by-injection is not playable. Reading a
telemetry counter that was set by a debug command proves nothing; the counter
must increment because real player input drove a real footfall whose sound
really fired, read back in PIE. The truth chain the player can see (boot lands,
ear hears) must be the SAME chain the number reports — otherwise we've built a
dashboard about a game that isn't happening.
