# Elementary: what it is NOT — audio_visual_sync/telemetry_accessors

It is not the footstep SOUND system itself — Ground_Sand_Sound owns making the
crunch (asset, trigger, mix); audio_visual_sync/telemetry_accessors owns
MEASURING that the crunch landed on time. That is its nearest neighbor and the
blur to guard against: fixing the accessors does not add a single decibel, and
importing a better footstep pack does not make count=0 truthful. The one
distinction that keeps them apart: Ground_Sand_Sound serves the player's ear;
the accessors serve the sleepwalker's clipboard. If a change can be heard, it
belongs to the sound feature; if it can only be graphed, it belongs here.
