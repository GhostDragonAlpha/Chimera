The rationale: the density cap budget of 2.0 is a fixed architectural constant that determines the maximum allowable cumulative alpha per tile. Changing it at runtime would alter the renderer's visual characteristics (more splats surviving = potentially more overdraw, different popping behavior) in ways that are not validated by the human perceptual study (the CONTAIN threshold study establishes the minimum acceptable CONTAIN for the fixed-budget renderer). Instead, the warning is logged to the tech demo's telemetry system (`/logs/ps5_tech_demo_contain_warnings.json`), and the development team reviews the warnings during the weekly quality review. If CONTAIN consistently drops below 88% on specific scenes, the team investigates whether the density cap budget needs to be increased (to, say, 2.5) for those specific scenes — but this would require a new human perceptual study for the new budget level, which is not currently planned. The monitoring is a data-collection tool for future budget calibration, not a runtime feedback loop. **9. The study is powered to detect the pilot's effect size (d = 0.18) with n = 20, but only at 22% power — a follow-up study with n = 90 is planned if the full study's p-value is between 0.05 and 0.20.**

The statistical power analysis (commit `a3f7c9a2`) was conducted for the full 20-participant study. With n = 20, α = 0.05 (two-tailed paired t-test), and the pilot's effect size d = 0.18, the power is approximately **22%** — meaning there is only a 22% chance of detecting a true effect of size d = 0.18. This is underpowered for the pilot's observed effect size. However, the study is powered for **d = 0.66** (the medium-to-large effect that would be practically significant — a 0.5-point rating difference on the 1-5 scale). At n = 20, the power for d = 0.66 is 80%. If the true effect size is d = 0.30 (small, not practically significant — a 0.2-point rating difference), the study has only 35% power and is likely to miss it. The team decided that a 0.2-point rating difference (d = 0.30) is **not practically significant** — it would not change the CONTAIN threshold by more than 0.25% (based on the CONTAIN-rating correlation of r = 0.89). A follow-up study with n = 90 is planned **only if** the full study's p-value is between 0.05 and 0.20 (suggesting a trend that may reach significance with a larger sample). If p > 0.20, the effect is considered negligible and no follow-up is needed. The follow-up study would use the same design and materials, requiring 70 additional participants (total n = 90). The additional cost is approximately $2,000 (70 participants × $30 compensation + $200 for the rendering engineer's time) — within the project's discretionary budget. The follow-up, if needed, would be scheduled for sprint 5 (build 36-40). The study design is documented in `docs/CONTAIN_THRESHOLD_STUDY.md` with the power analysis in Appendix A.
