**9. The p < 0.20 follow-up trigger is justified by a cost-benefit analysis: the cost of a Type II error (missing a 0.25% CONTAIN adjustment) is low because the CONTAIN gate threshold is set in 1% increments, and a 0.25% adjustment would not change the gate threshold from 90% to 89.75% (the gate uses 1% increments: 90%, 89%, etc.). A 0.25% CONTAIN change is within the measurement noise of the CONTAIN metric (±0.02% from radix sort non-determinism, ±0.03% from total CI variance per the build 30 analysis).**

The cost-benefit analysis (commit `a3f7c9aa`) was documented in the study design's Appendix A. The CONTAIN gate threshold is set in **1% increments** (e.g., 90%, 89%, 88% — the current threshold is 85.5% but will be revised to the nearest 1% value after the study). A 0.25% CONTAIN adjustment (from, say, 89.5% to 89.75%) would not change which 1% bucket the threshold falls in — it would still be 89% or 90%. The measurement noise of the CONTAIN metric is ±0.03% (from total CI variance, measured at build 30), so a 0.25% adjustment is only 8× the noise floor — detectable but not practically significant for the gate threshold. The cost of missing a 0.25% adjustment is therefore $0 (it would not change the gate threshold). The follow-up study's $2,000 cost would not be justified for a change that has zero impact on the gate threshold. The p < 0.20 trigger is conservative enough: if the effect is large enough to change the gate threshold by 1% (the smallest unit of change), it would correspond to d ≈ 0.80 (a 0.6-point rating difference), which has >99% power to be detected with n = 20 and would easily achieve p < 0.05, triggering the follow-up and resulting in a 1% threshold adjustment. The p < 0.20 threshold catches effects that are trending toward significance (p between 0.05 and 0.20) and may represent d ≈ 0.40-0.60 (a 0.3-0.5 point rating difference, corresponding to a 0.5-0.75% CONTAIN adjustment) — still below the 1% threshold increment but worth investigating with a larger sample. The cost-benefit analysis concludes that the p < 0.20 trigger is appropriate: it filters out negligible effects (p > 0.20, d < 0.40) that would not change the gate threshold, while catching trending effects that might. The $2,000 follow-up cost is justified for effects that approach the 1% threshold increment. The analysis is documented in `docs/CONTAIN_THRESHOLD_STUDY.md` Appendix A, section A.3 "Cost-Benefit Analysis of Follow-Up Trigger Threshold" (commit `a3f7c9aa`).
