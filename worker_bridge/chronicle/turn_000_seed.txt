DEEP SPACE TRADER — EDUCATIONAL MECHANIC DESIGN BRIEF

The game already has: trading, navigation, ship systems, exploration,
factions, combat, resource management, procedural generation.

REQUIREMENT: Design one educational mechanic that teaches real knowledge
through the EXISTING gameplay loop. Not a new system — an enhancement
to something that already works.

The mechanic must:
1. Teach something real (economics, physics, astronomy, biology, game theory)
2. Fit within existing systems (no new engine dependencies)
3. Be implementable in a single Foundry cycle
4. Make the game more famous, not just more complex

OUTPUT FORMAT: A single JSON object with:
- mechanic_name: string
- teaches: what real-world knowledge
- existing_system: which game system it enhances
- implementation: what code changes in what files
- player_experience: how the player encounters it

This is not a discussion. This is a design brief. Produce the output.
